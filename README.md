# Сайт для планирования личного бюджета с аналитикой расходов

![Python](https://img.shields.io/badge/Python-3.10+-blue?logo=python)
![Django](https://img.shields.io/badge/Django-4.x-092E20?logo=django)
![Status](https://img.shields.io/badge/Status-Pet--Project-brightgreen)

Веб-приложение для ведения личных финансов, контроля доходов и расходов, планирования категорий бюджета и наглядной аналитики. Проект разработан на фреймворке **Django (Python)**.

## Основные возможности

* **Гибкая организация через таблицы:** группировка финансовых данных по удобным периодам (месяцы, кварталы, годы).
* **Управление счетами и сбережениями:** поддержка нескольких счетов с динамическим пересчетом баланса в реальном времени.
* **Бюджетирование и лимиты:** планирование ожидаемых трат и доходов по категориям, контроль остатка лимита до выхода за рамки бюджета.
* **Учет транзакций:** детальная запись доходов и расходов с привязкой к счетам и категориям.
* **Умная аналитика:** возможность исключать выбранные категории или отдельные транзакции из расчетов (например, переводы между своими счетами, чтобы не искажать статистику трат).
* **Безопасность и разграничение доступа:** регистрация, авторизация пользователей и панель администратора.

## 📖 Руководство пользователя

### 1. Авторизация и регистрация
При первом запуске открывается страница входа. Новые пользователи могут зарегистрироваться, а администраторы — перейти в стандартную панель управления Django.

### 2. Таблицы (периоды планирования)
Таблица — основной контейнер для финансовых записей. Вы можете создавать отдельные таблицы под каждый месяц, квартал или год. Доступны функции переименования и удаления.

<img width="512" height="255" alt="image" src="https://github.com/user-attachments/assets/88f122fc-bcb0-44c6-9c6b-e98c2476c147" />

> [!WARNING]
> При удалении таблицы безвозвратно удаляются все связанные с ней счета, категории и транзакции!

---

### 3. Начальная настройка бюджета
Внутри каждой таблицы рекомендуется сначала настроить базовые сущности:

1. **Сбережения / Счета (`Сбережения`):**
   * Добавьте ваши кошельки, банковские карты и накопительные счета.
   * Укажите стартовую сумму — далее система автоматически пересчитывает баланс на основе транзакций.

2. **Категории и лимиты (`Планы`):**
   * Задайте категории ожидаемых расходов и доходов с лимитами.
   * Отслеживайте, сколько средств осталось потратить до превышения лимита.
   * Отметьте чекбокс исключения из аналитики для служебных категорий (например, внутренних переводов).

### 4. Ведение транзакций
* **Траты:** списание средств с выбранного счета с привязкой к категории расходов.
* **Доходы:** поступление средств на выбранный счет.
* Каждую операцию можно индивидуально включить или исключить из аналитического отчета.
